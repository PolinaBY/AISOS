Предназначен для фиксации факта и результатов прохождения теста сотрудником. Документ создается автоматически при начале тестирования и содержит детальную информацию по каждому вопросу: ответы пользователя, результаты проверки, а для ручных ответов — комментарий GigaChat.

Открыть список тестирования можно из раздела Результаты и аналитика с помощью команды Тестирование.

Просмотр документов доступен пользователям с ролями Руководитель и Проверяющий

Реквизиты

  • Номер (Строка) Уникальный номер документа (формируется автоматически) 
  • Дата (Дата) Дата и время прохождения теста (заполняется автоматически) 
  • Сотрудник (СправочникСсылка.Сотрудники) Сотрудник, проходивший тестирование. Заполняется автоматически из сеанса 
  • Тест (СправочникСсылка.Тесты) Тест, по которому проводилось тестирование 
  • Блок вопросов (СправочникСсылка.БлокиВопросов) Блок вопросов, по которому проводилось тестирование 
  • Необходимый процент выполнения (Число) Процент правильных ответов, необходимый для успешного прохождения блока. Заполняется автоматически из настроек блока в тесте. Недоступен для изменения пользователем
  • Подтвержден (Булево) Признак подтверждения документа. После подтверждения проверяется необходимость переназначения теста сотруднику (автоматическое переключение на следующий по приоритету)
  • Организация (СправочникСсылка.Организации) Организация, в которой работает сотрудник. Заполняется автоматически из карточки сотрудника 

Табличная часть «Вопросы с выбором ответа»


  • Вопрос (СправочникСсылка.Вопросы) Ссылка на вопрос из справочника вопросов 
  • Текст вопроса (Строка) Текст вопроса (сохраняется на момент тестирования для защиты от изменений) 
  • Тип вопроса (СправочникСсылка.ТипыВопросов) Тип вопроса (заполняется автоматически) 
  • Ответ пользователя  (Строка) Выбранный пользователем вариант ответа (например, «Вариант 1; Вариант 3») 
  • Результат (Булево) Результат проверки ответа: Истина — верно, Ложь — неверно 

Табличная часть «Вопросы с ручным вводом


  • Вопрос (СправочникСсылка.Вопросы) Ссылка на вопрос из справочника вопросов 
  • Текст вопроса (Строка) Текст вопроса (сохраняется на момент тестирования для защиты от изменений) 
  • Тип вопроса (СправочникСсылка.ТипыВопросов) Тип вопроса (заполняется автоматически) 
  • Ответ пользователя (Строка) Текст, введенный пользователем в качестве ответа 
  • Ответ GigaChat (Строка) Подробный комментарий от GigaChat по результатам проверки (причина зачисления ответа как верного или неверного) 
  • Результат (Булево) Результат проверки ответа: Истина — верно, Ложь — неверно 

Создание


  1. Сотрудник выбирает тему и блок вопросов.
  2. Нажимает кнопку Начать тест в обработке Тестирование сотрудника
  3.  Система автоматически:
  4. Создает документ Тестирование с незаполненными табличными частями
    1. Заполняет реквизиты (сотрудник, тест, блок, необходимый процент, организация)
    2. Устанавливает флаг Подтвержден = Ложь
  5. Сохраняет документ и запоминает ссылку для последующего заполнения.

Заполнение результатов


  1. Сотрудник последовательно отвечает на вопросы.
  2. При завершении кнопка Завершить ответы сохраняются в соответствующие табличные части документа.
  3. Для вопросов с ручным вводом при завершении теста выполняется проверка через GigaChat, результат и комментарий сохраняются в документ.

Подтверждение


  1. Администратор или руководитель тестирования проверяет результаты и апелляции(если есть).
  2. При необходимости корректирует результаты (вручную).
  3. Устанавливает флаг Подтвержден = Истина.
  4. Система проверяет:
    1. Все ли блоки теста пройдены сотрудником с необходимым процентом
    2. Если да — автоматически переназначает сотрудника на следующий тест по приоритету
