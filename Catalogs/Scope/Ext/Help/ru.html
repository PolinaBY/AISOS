Справочник предназначен для хранения областей действия (scope), используемых при авторизации в сервисе GigaChat. Каждая область действия определяет набор прав и ресурсов, к которым приложение может получить доступ при обращении к API GigaChat.

Открыть список областей действия можно из раздела НСИ с помощью команды Настройки giga chat.

Ведение списка областей действия осуществляет администратор или руководителем.

Справочник является не иерархическим, не подчинен другим справочникам.

Использование в конфигурации


Значения из справочника Scope используются в модуле GigaChatРабота при формировании запросов к API GigaChat. Константа Scope должна содержать ссылку на соответствующий элемент справочника.

Настройка подключения


Для корректной работы генерации вопросов через GigaChat необходимо:

  1. В константе Scope выбрать значение из справочника.
  2. Указать значение в константе AuthorizationKey (ключ авторизации).

Удаление области действия


Внимание! Удаление области действия, используемой в настройках подключения к GigaChat, приведет к невозможности генерации вопросов.

Перед удалением убедитесь, что данная область действия не выбрана в константе Scope.

Для удаления области действия:
  1. Выделите запись в списке.
  2. Нажмите кнопку Удалить или используйте клавишу Delete.
  3. Подтвердите удаление.

Предопределенные элементы


В конфигурации созданы следующие предопределенные элементы:
  • GIGACHAT_API_B2B - Область действия для сегмента «бизнес для бизнеса». Предоставляет доступ к функциям GigaChat для корпоративных клиентов с возможностью настройки под отраслевые задачи.
  • GIGACHAT_API_CORP - Область действия для корпоративного сегмента. Предоставляет полный доступ к функциям GigaChat для использования внутри организации, включая интеграцию с корпоративными системами.
  • GIGACHAT_API_PERS - Область действия для персонального сегмента. Предоставляет доступ к базовым функциям GigaChat для индивидуальных пользователей с ограничениями по объему запросов.

Предопределенные элементы не могут быть удалены пользователем, но их наименование и описание могут быть изменены (не желательно).
