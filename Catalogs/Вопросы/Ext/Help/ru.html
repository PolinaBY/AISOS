Предназначен для ведения базы тестовых вопросов, используемых при проведении тестирования сотрудников. Каждый вопрос может содержать текст, изображения, относиться к определенному блоку и иметь один из двух типов ответа: выбор из вариантов или ручной ввод.

Открыть список вопросов можно из раздела Управление тестами с помощью команды Вопросы.

Ведение списка вопросов могут осуществлять сотрудники с ролью Методолог или Руководитель тестирования

Методолог и Руководитель тестирования  имеют полные права на создание, редактирование и удаление вопросов, настройку вариантов и эталонных ответов.

Остальные пользователи имеют доступ только к просмотру вопросов в составе тестов.

Ввод вопроса


  1. Нажмите кнопку Создать.
  2. Заполните обязательные поля:
    1. Блок — выберите тематический блок из справочника Блоки вопросов
    2. Тип вопроса — выберите Выбор ответа или Ручной ввод
  3. В поле Вопрос введите текст вопроса. Для вставки изображения используйте контекстное меню (правая кнопка мыши → Вставить → Рисунок).
  4. В зависимости от выбранного типа вопроса:
    1. Выбор ответа — добавьте варианты ответов, отметив правильные.
    2. Ручной ввод — добавьте эталонный ответ для сравнения.
  5. Установите флажок Включать в тест, если вопрос должен участвовать в тестировании.

Генерация вопроса через GigaChat


Для автоматической генерации вопроса используйте кнопку Сгенерировать на форме вопроса.

Условия для генерации:
  • Должен быть заполнен блок вопросов.
  • Должен быть выбран тип вопроса.
  • Настройки подключения к GigaChat должны быть корректно заполнены в константах.

Если в поле вопроса уже есть текст, система предложит использовать его в качестве контекста для генерации нового вопроса.

Редактирование вопроса


После сохранения вопроса становятся доступными для редактирования:
  • Варианты ответов (для типа «Выбор ответа») — добавляются, изменяются и удаляются в подчиненном списке.
  • Эталонные ответы (для типа «Ручной ввод») — добавляются, изменяются и удаляются в подчиненном списке.

Важно: Изменение типа вопроса после сохранения возможно, но приведет к удалению уже созданных вариантов или эталонных ответов.

Поиск и отбор


Для удобной работы со списком вопросов доступны следующие возможности:

Отбор по тесту — позволяет просматривать вопросы только выбранного теста.

Работа с вариантами ответов (для типа «Выбор ответа»)


Варианты ответов отображаются в подчиненном списке на форме вопроса.

Добавление варианта:


  1. Нажмите кнопку Создать в командной панели списка вариантов.
  2. Укажите текст варианта и установите флажок Верный, если вариант является правильным.

Редактирование варианта:

Дважды кликните по строке варианта или используйте команду Изменить в контекстном меню.

Удаление варианта:

Выделите вариант и нажмите Удалить или используйте клавишу Delete.

Работа с эталонными ответами (для типа «Ручной ввод»)


Эталонные ответы используются для автоматической проверки ответов сотрудников через GigaChat.

Добавление эталона:
1. Нажмите кнопку Создать в командной панели списка эталонов.
2. Введите текст эталонного ответа.

Установка изображения


Поле Вопрос поддерживает вставку изображений.

Способ вставки:
1. Установите курсор в поле форматированного документа.
2. Нажмите правую кнопку мыши.
3. Выберите Вставить → Рисунок
4. Выберите файл изображения на компьютере.

Изображение сохраняется вместе с вопросом в базе данных. Поддерживаются форматы: JPEG, PNG, BMP.

Копирование вопроса


Для создания аналогичного вопроса используйте команду Копировать в контекстном меню списка. Будут скопированы:
  • Текст вопроса.
  • Изображения.
  • Тип вопроса.
  • Блок вопросов.

    • Не копируется: Ответы принадлежат определенному вопросу.

    Удаление вопроса


    Для удаления вопроса:
    1. Выделите вопрос в списке.
    2. Нажмите кнопку Удалить или используйте клавишу Delete.
    3. Подтвердите удаление.
