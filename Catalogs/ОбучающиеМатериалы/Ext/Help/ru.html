Предназначен для хранения учебных материалов, необходимых для подготовки к тестированию по определенному блоку вопросов. Материалы могут содержать ссылки на внешние ресурсы (статьи, видео, документацию) и текстовые описания.

Открыть список обучающих материалов можно из раздела Нормативно-справочная информация из справочника Блоки вопросов.

Ведение списка материалов осуществляют сотрудники с ролью Методолог или Руководитель тестирования.

Справочник является подчиненным по отношению к справочнику Блоки вопросов. Каждый обучающий материал привязан к конкретному блоку.

Реквизиты


  • СсылкаНаМатериал  (Строка)  URL-адрес внешнего ресурса (статья, видео, документация) 
  • Описание (Строка) Краткое описание материала, рекомендации по изучению 
  • Владелец (СправочникСсылка.БлокиВопросов) Блок вопросов, к которому относится материал (заполняется автоматически) 

Ввод обучающего материала


  1. Откройте форму блока вопросов.
  2. В табличной части Обучающие материалы нажмите кнопку Создать.
  3. Заполните поля (владелец подставится автоматически).
  4. Нажмите Записать и закрыть.

Отображение в форме тестирования


При прохождении тестирования сотрудником:

  1. Сотрудник выбирает Блок вопросов на начальной странице.
  2. Справа от списка блоков отображается таблица обучающих материалов, относящихся к выбранному блоку.
  3. Для перехода по ссылке достаточно нажать на строку с материалом — откроется внешний ресурс в браузере.

Навигация по ссылке


При нажатии на строку материала в таблице выполняется переход по URL, указанному в реквизите СсылкаНаМатериал. Ссылка открывается в браузере по умолчанию.

Рекомендации по заполнению


  • СсылкаНаМатериал должна начинаться с `http://` или `https://`, иначе переход может не работать.
  • Описание рекомендуется заполнять для пояснения, что именно нужно изучить.
