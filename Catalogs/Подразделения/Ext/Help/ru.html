Предназначен для ведения списка структурных подразделений организаций. Позволяет отражать иерархическую структуру компании для последующего отбора сотрудников при назначении тестов и анализе результатов.

Открыть список подразделений можно из раздела Нормативно-справочная информация с помощью команды Подразделения.

Ведение списка подразделений осуществляют сотрудники с ролью Администратор или Руководитель по персоналу.

Справочник является не иерархическим.

Реквизиты


  • Наименование (Строка)  Название подразделения (например, «Отдел разработки», «Бухгалтерия», «Отдел тестирования») 
  • Владелец (СправочникСсылка.Организации) Организация, к которой относится подразделение 

Ввод подразделения


  1. Нажмите кнопку Создать.
  2. Заполните поле Наименование — укажите название подразделения.
  3. Заполните поле Владелец — выберите организацию, к которой относится подразделение.
  4. Нажмите Записать и закрыть.
