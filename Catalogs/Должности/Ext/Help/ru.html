Предназначен для хранения перечня должностей, которые могут занимать сотрудники в организации. Должность является дополнительной характеристикой сотрудника и используется для классификации персонала.

Открыть список должностей можно из раздела Нормативно-справочная информация с помощью команды Должности.

Ведение списка должностей осуществляют сотрудники с ролью Администратор или Руководитель.

Справочник является не иерархическим.

Реквизиты


  • Наименование (Строка) - Название должности (например, «Программист», «Тестировщик», «Аналитик») 
  • Организация (СправочникСсылка.Организации) - Организация, в которой существует данная должность 

Ввод должности


  1. Нажмите кнопку Создать.
  2. Заполните поле Наименование— укажите название должности.
  3. Заполните поле Организация — выберите организацию, в которой введена данная должность.
  4. Нажмите Записать и закрыть.

Рекомендации по заполнению

  • Наименование должно быть кратким и понятным.
  • Организация заполняется обязательно, если в конфигурации ведется учет по нескольким организациям.
  • Для одной организации могут существовать одинаковые должности (например, «Программист» в разных отделах), но рекомендуется использовать уникальные наименования.
