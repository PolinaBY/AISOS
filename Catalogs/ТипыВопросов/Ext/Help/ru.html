Предназначен для классификации вопросов по формату ответа. Определяет, каким образом сотрудник будет отвечать на вопрос при прохождении тестирования.

Открыть список типов вопросов можно из раздела Управление тестами с помощью команды Типы вопросов.

Ведение списка типов вопросов осуществляют сотрудники с ролью Методолог или Руководитель.

Справочник является не иерархическим, не подчинен другим справочникам.

Реквизиты


  • Наименование (Строка) Название типа вопроса (отображается пользователю) 
  • МножественныйВыбор (Булево) Определяет, может ли сотрудник выбрать несколько вариантов ответа. Если флаг установлен — допускается выбор нескольких вариантов 

Предопределенные элементы


В справочнике предусмотрены следующие предопределенные элементы:

  • ВыборОтвета Сотрудник выбирает ответ(ы) из предложенных вариантов. Флаг «МножественныйВыбор» определяет, можно ли выбрать несколько вариантов 
  • РучнойВвод Сотрудник вводит ответ в текстовое поле. Ответ сравнивается с эталоном (вручную или через GigaChat) 

Редактирование типа вопроса


  1. Выделите тип вопроса в списке.
  2. Дважды кликните левой кнопкой мыши или нажмите кнопку Изменить.
  3. При необходимости измените флаг МножественныйВыбор.
  4. Нажмите Записать и закрыть.

Внимание! Изменение предопределенных элементов может повлиять на работу вопросов. Рекомендуется изменять только флаг «МножественныйВыбор» для типа «Выбор ответа».
