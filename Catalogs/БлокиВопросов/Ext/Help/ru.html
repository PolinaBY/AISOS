Предназначен для группировки вопросов по тематическим блокам, разделам или уровням сложности. Используется при формировании тестов для отбора вопросов из определенных блоков.

Открыть список блоков вопросов можно из раздела Управление тестами с помощью команды Блоки вопросов.

Ведение списка блоков вопросов могут осуществлять сотрудники с ролью Методолог или Руководитель тестирования.

Справочник является иерархическим, что позволяет создавать вложенные блоки для детализации тематических разделов.

Пример иерархии


Блоки вопросов
├── 1С:Предприятие
│   ├── Управляемые формы
│   ├── Запросы
│   └── БСП
├── Программирование
│   ├── Алгоритмы
│   ├── Структуры данных
│   └── ООП
└── Базы данных
    ├── SQL
    └── Индексы
... 

Ввод блока вопросов


Создание блока


  1. Нажмите кнопку Создать.
  2. Заполните поле Наименование — укажите название блока (например, «1С:Предприятие»).
  3. При необходимости заполните Обучающие материалы по блоку
  4. Нажмите Записать и закрыть.

Редактирование блока вопросов


  1. Выделите блок в списке.
  2. Дважды кликните левой кнопкой мыши или нажмите кнопку Изменить.
  3. Измените наименование.
  4. Нажмите Записать и закрыть.

Удаление блока вопросов


Внимание! При удалении блока вопросы, принадлежащие удаляемому блоку, остаются в справочнике Вопросы, но поле Блок становится пустым.

Для удаления блока:
  1. Выделите блок в списке.
  2. Нажмите кнопку Удалить или используйте клавишу Delete.
  3.  Подтвердите удаление.
