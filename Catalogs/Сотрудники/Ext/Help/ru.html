Предназначен для ведения списка сотрудников, участвующих в процессе тестирования. Сотрудник является основным субъектом, для которого назначаются тесты, проводятся тестирования и фиксируются результаты.

Открыть список сотрудников можно из раздела Нормативно-справочная информация с помощью команды Сотрудники.

Ведение списка сотрудников осуществляют сотрудники с ролью Администратор или Руководитель.

Структура справочника


Справочник является не иерархическим, не подчинен другим справочникам.

Реквизиты


  • Наименование (Строка) Полное имя сотрудника (Фамилия, Имя, Отчество) 
  • Организация (СправочникСсылка.Организации) Организация, в которой работает сотрудник 
  • Подразделение (СправочникСсылка.Подразделения) Структурное подразделение сотрудника 
  • Должность (СправочникСсылка.Должности) Должность, занимаемая сотрудником 
  • Грейд (СправочникСсылка.Грейды) Уровень квалификации сотрудника (дополнительная информация) 
  • ДатаПриема  (Дата)  Дата трудоустройства сотрудника
  • ДатаУвольнения (Дата) Дата увольнения сотрудника (если поле заполнено и дата наступила, доступ в систему блокируется) |

Ввод сотрудника


  1. Нажмите кнопку Создать.
  2. Заполните поле Наименование — укажите фамилию, имя, отчество сотрудника.
  3. Заполните поле Организация — выберите организацию.
  4. При необходимости заполните поля:
    1. Подразделение — выберите структурное подразделение.
    2. Должность — выберите должность.
    3.  Грейд — выберите уровень квалификации.
  5. ДатаПриема — укажите дату трудоустройства.
  6. Нажмите Записать и закрыть.

Блокировка пользователя при увольнении


При заполнении реквизита ДатаУвольнения системой выполняется автоматическая блокировка доступа сотрудника в программу.

  • При записи сотрудника система проверяет:
    • Заполнена ли дата увольнения.
    • Наступила ли дата увольнения.
  • Если дата увольнения наступила, система автоматически:
    • Отключает аутентификацию связанного пользователя.
    • Помечает пользователя как Недействительный.
    • Запрещает вход в программу под этим пользователем.
