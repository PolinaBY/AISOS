Предназначен для хранения комплексных тестов, состоящих из блоков вопросов. Тест определяет набор тем (блоков), которые должен пройти сотрудник, порядок их прохождения и критерии успешности.

Открыть список тестов можно из раздела Управление тестами с помощью команды Тесты.

Ведение списка тестов осуществляют сотрудники с ролью Методолог или Руководитель тестирования.

Справочник является не иерархическим.

Реквизиты


  • Наименование (Строка) Название теста (например, «Квалификационный тест для разработчиков») 
  • Организация (СправочникСсылка.Организации) Организация, для которой разработан тест
  • Подразделение (СправочникСсылка.Подразделения) Подразделение, для которого разработан тест 
  • Приоритет  (Число) Порядок прохождения тестов. Чем меньше число, тем выше приоритет. После полного прохождения текущего теста система автоматически переключится на следующий по приоритету

Табличная часть «Состав теста»


  • Блок вопросов (СправочникСсылка.БлокиВопросов) Блок вопросов, включаемый в тест. Определяет тематическую область и набор вопросов
  • Количество вопросов (Число) Количество вопросов, включенных в блок (определяется автоматически)
  • Проходной процент (Число) Процент правильных ответов, необходимый для успешного прохождения блока (значение от 1 до 100). Например, 70 означает, что сотрудник должен правильно ответить не менее чем на 70% вопросов блока 
  • Случайный порядок (Булево) Если флаг установлен, вопросы из блока выводятся в случайном порядке при каждом прохождении теста
  • Включать в тест (Булево) Если флаг установлен, блок включается в тест. Позволяет временно исключать блоки без удаления из состава

Ввод теста


  1. Нажмите кнопку Создать.
  2. Заполните поле Наименование — укажите название теста.
  3. При необходимости заполните поля Организация и Подразделение.
  4. Укажите Приоритет — число, определяющее порядок прохождения.
  5. В табличной части Состав теста добавьте блоки вопросов:
    1. Выберите Блок вопросов из справочника.
    2. Укажите Проходной процент— порог успешного прохождения блока.
    3. При необходимости установите Случайный порядок для перемешивания вопросов.
    4. Установите Включать в тест (по умолчанию Истина).
  6. Нажмите Записать и закрыть.

Приоритет 


Система автоматически управляет очередностью прохождения тестов сотрудником.

  1. Каждый тест имеет числовой Приоритет (чем меньше число, тем выше приоритет).
  2. Сотрудник начинает прохождение с теста, имеющего наименьшее значение приоритета.
  3. После успешного прохождения всех активных блоков текущего теста (с достижением необходимого процента в каждом блоке) система автоматически:
    1. Переключает сотрудника на следующий тест по приоритету.
    2. Обновляет назначенный тест в регистре сведений «Тесты сотрудников».

Пример


| 10 | Вводный тест | Пройден → переход к следующему 
| 20 | Базовый тест | Активный |
| 30 | Продвинутый тест | Ожидает |

Рекомендации по заполнению


  • Приоритет рекомендуется назначать с шагом 10 (10, 20, 30…) для возможности вставки новых тестов между существующими.
  • Проходной процент для блоков рекомендуется устанавливать не менее 70 для адекватной оценки знаний.
  • При создании теста сначала добавьте блоки вопросов, затем укажите остальные реквизиты.
  • Для временного исключения блока из теста используйте флаг Включать в тест (Ложь), не удаляя блок из состава.
