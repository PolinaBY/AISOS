Предназначена для массовой загрузки вопросов из файла Microsoft Excel в справочник Вопросы.

Открыть обработку можно из раздела Управление тестами с помощью команды Импорт вопросов из Excel.

Формат файла Excel


Файл должен содержать колонки (первая строка — заголовки):

  • ТекстВопрос — Текст вопроса. Обязательное поле.
  • ТипВопроса — «Выбор ответа» или «Ручной ввод»
  • Блок — Наименование блока вопросов. При импорте блоки создаются автоматически.
  • ЭталонныеОтветы — для типа «Ручной ввод» 
  • ВариантыОтветов — Для вопросов типа «Выбор ответа». Варианты ответов перечисляются через точку с запятой (;). Правильный ответ отмечается знаком + в начале варианта.

Работа с обработкой


  • Выгрузить шаблон — Нажмите кнопку «Выгрузить шаблон», чтобы скачать готовый файл Excel с заголовками и примером заполнения. Этот шаблон можно использовать для подготовки данных.
  • Выбрать файла — Нажмите кнопку «Выбрать файл» и укажите путь к файлу Excel. После выбора файл загрузится и откроется в табличном документе для предварительного просмотра.
  • Загрузить — Нажмите кнопку «Загрузить данные» – обработка прочитает файл, проверит корректность колонок и начнёт импорт вопросов. 

Что происходит при импорте


  • Для вопросов с выбором ответа создаются варианты ответов
  • Для вопросов с ручным вводом создаются эталонные ответы
  • При повторном импорте создаются новые вопросы (существующие не обновляются)
