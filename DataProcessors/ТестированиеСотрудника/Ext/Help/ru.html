Предназначена для прохождения тестов сотрудниками. Позволяет выбрать тест и блок вопросов, изучить обучающие материалы, ответить на вопросы и получить результат.

Открыть обработку можно из рабочего стола сотрудника или из раздела Тестирование с помощью команды Тестирование сотрудника.
Дополнительно перейти можно из начальной страницы сотрудника Информативной панели сотрудника

Что можно сделать


  • Из выпадающего списка выбирается доступный тест, назначенный сотруднику. Если ни один тест не назначен появится соответствующее сообщение.
  •  Ниже отображаются блоки вопросов, входящие в этот тест.
  • При выборе блока справа появляются ссылки на обучающие материалы. При нажатии на ссылку можно перейти к материалу и ознакомиться.
  • После выбора блока нажимается кнопка Начать. Открывается первый вопрос.
  • Прохождение теста.
    • Сверху отображается прогресс (например, «Вопрос 2 из 4»). Ниже — текст вопроса. В зависимости от типа вопроса:
      • Выбор ответа — отображаются варианты ответов, нужно отметить верный (один или несколько)
      • Ручной ввод — отображается поле для ввода текста
    • Доступны кнопки Назад, Далее, Завершить. 
    • Блоки можно проходить неограниченное количество раз.
  • После завершения отображается количество верных ответов из общего числа вопросов. Доступны действия:
    • Возврат на начальную страницу выбора теста и блока, с помощью кнопки Закрыть.
    • Открыть форму для ввода текста апелляции с помощью отметки Подать апелляцию. После заполнения апелляция отправляется. При отказе от заполнения можно вернуться к результатам
