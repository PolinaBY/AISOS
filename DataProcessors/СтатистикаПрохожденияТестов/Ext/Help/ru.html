Предназначена для анализа результатов тестирования в разрезе организационной структуры. Позволяет руководителю оценить успешность прохождения тестов сотрудниками.

Открыть обработку можно из раздела Результаты и аналитика с помощью команды Статистика прохождения тестов.

Что можно сделать


  • С помощью настроек отображения можно установить фильтры для анализа:
    • Организация
    • Подразделение
    • Сотрудник
    • Тест
  • Ниже на отдельных страницах отображается информация:
    • По организации— сводные данные по выбранной организации
    • По подразделению — детализация по структурным подразделениям
    • По сотруднику — индивидуальные результаты сотрудников
  • Данные представлены в виде круговых диаграмм, показывающих: соотношение успешно и не успешно пройденных тестов, процент выполнения по блокам, достижение проходного порога
