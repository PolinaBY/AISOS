Предназначена для гибкой настройки тестов: формирования состава блоков, отбора вопросов, установки количества вопросов и проходных процентов.

Открыть обработку можно из раздела Управление тестами с помощью команды Конструктор тестов.

Что можно сделать


  • Выбирается тест, который нужно настроить. Ниже отображаются блоки, входящие в этот тест.
  • Для каждого блока можно указать:
    • Сколько вопросов будет взято из блока (должно быть меньше или равно общему количеству вопросов в блоке)
    • Блок включается или исключается из теста
    • При включении случайного порядка вопросы блока будут выпадать в случайном порядке, все вопросы блока автоматически включаются в тест
    • Процент правильных ответов, необходимый для успешного прохождения блока
  • При выборе блока рядом отображается список всех вопросов, принадлежащих этому блоку.
  • Для каждого вопроса можно установить флаг «Включать в тест» (включить или выключить). Находится в командной панели. Доступны следующие команды:
    • Выбрать все — включить все вопросы блока
    • Убрать все — отключить все вопросы блока
