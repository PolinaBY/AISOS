Предназначена для массового назначения тестов сотрудникам с возможностью отбора по организационной структуре.

Открыть обработку можно из раздела Управление тестами с помощью команды Назначение тестов сотрудникам.

Что можно сделать


  • Можно отобрать сотрудников по:
    • Организации
    • Подразделению
    • Должности
  • После установки отборов в динамическом списке отображаются сотрудники, соответствующие выбранным критериям.
  • Далее указывается тест, который будет назначен сотрудникам.
  • При необходимости устанавливается срок, до которого тест должен быть пройден. Если дата не указана — срок не ограничен.
  • Далее выделяются один или несколько сотрудников в списке, нажимается кнопка Назначить. Система записывает назначение в регистр сведений Тесты сотрудников. Если для сотрудника уже назначен этот тест, обновляется только крайняя дата прохождения.
