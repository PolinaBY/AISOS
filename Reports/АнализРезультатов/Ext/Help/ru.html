Позволяет ответить на вопросы:

  • Какие ответы дал сотрудник на каждый вопрос теста?

  • Какие вопросы были отвечены верно, а какие нет?

  • По каким вопросам требуется дополнительное изучение материала?

  • Как распределились результаты по организации, сотрудникам, тестам и блокам?


Открыть отчет можно из раздела Результаты и Аналитика с помощью команды Анализ Результатов.

Работа с отчетом


  • Установка отборов Позволяет ограничить отчет по организации, сотруднику, тесту, документу тестирования, блоку или вопросу 
  • Анализ результатов Каждая строка отчета показывает ответ сотрудника и его результат (верно/неверно) 

Параметры отбора


  • Организация - Отбор по организации, в которой работает сотрудник 
  • Сотрудник - Отбор по конкретному сотруднику 
  • Тест - Отбор по наименованию теста 
  • Ссылка -  Отбор по документу тестирования 
  • Блок - Отбор по блоку вопросов 
  • Вопрос - Отбор по конкретному вопросу 

Структура отчета


  • Организация - Организация, в которой работает сотрудник 
  • Сотрудник - ФИО сотрудника, проходившего тестирование 
  • Тест - Наименование теста 
  • Ссылка - Ссылка на документ «Тестирование». При нажатии открывается документ для просмотра 
  • Блок - Наименование блока вопросов 
  • Вопрос - Текст вопроса 
  • Ответ - Ответ, данный сотрудником (выбранные варианты или введенный текст) 
  • Результат - Результат проверки: «Верно» (зеленый) или «Неверно» (красный)
