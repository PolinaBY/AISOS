Позволяет ответить на вопросы
  • Какие тесты и блоки проходил сотрудник?
  •  Какой процент правильных ответов получен по каждому блоку?
  • Достигнут ли необходимый проходной процент для успешного прохождения блока?
  • Насколько хорошо сотрудник освоил материал по сравнению с требованиями?

Открыть отчет можно из раздела Тестирование с помощью команды Результаты тестирования

Работа с отчетом


  • Выбор сотрудника. Отчет выдается по конкретному сотруднику, через параметры сеанса
  • Выбор периода. Отчет формируется по состоянию на указанную дату 
  • Нажатие на ячейку. Выводит расшифровку — список решенных тестов по данному блоку 
  • Группировка. Результаты сгруппированы по тестам и блокам вопросов
  • Оформление. Каждая строка отмечена цветовым индикатором прохождения, в зависимости от пройденного процента в рамках блока

Параметры отчета


  • Сотрудник. Сотрудник, по которому формируется отчет. Получение через параметры сеанса. 
  • Период. Дата, на которую формируется срез результатов. Учитываются результаты прохождения тестов, завершенные до указанной даты |

Структура отчета

  • Сотрудник ФИО сотрудника 
  • Тест Наименование теста
  • Блок вопросов Наименование блока вопросов
  • Всего вопросов Количество вопросов в блоке на момент тестирования 
  • Верных ответов Количество правильных ответов, данных сотрудником 
  • Процент выполнения Процент правильных ответов от общего числа вопросов (рассчитывается как `Верных ответов / Всего вопросов * 100`) 
  • Проходной процент Процент правильных ответов, необходимый для успешного прохождения блока (задается в тесте)
  • Прохождение теста Показывает, насколько сотрудник превысил или не достиг порога 

Интерпретация результатов


Процент выполнения

  • 100% Все вопросы отвечены правильно 
  • 70–99% Большинство вопросов отвечено правильно 
  • 50–69% Половина и более вопросов отвечено правильно 
  • Менее 50% Преобладают неправильные ответы 

Прохождение теста

  • 100%. Успешно. Сотрудник достиг или превысил необходимый порог 
  • Менее 100%. Не успешно. Сотрудник не достиг необходимого порога
