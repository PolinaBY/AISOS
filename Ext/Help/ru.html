Конфигурация предназначена для автоматизации процессов тестирования сотрудников организации. Позволяет создавать базу тестовых вопросов, формировать тесты, назначать их сотрудникам, проводить тестирование и анализировать результаты.

  • Вести список сотрудников, организаций, подразделений, должностей, грейдов, блоков вопросов, типов вопросов, обучающих материалов.
  • Формировать тесты, состоящие из блоков вопросов, устанавливать количество вопросов, проходной процент, случайный порядок, гибко настраивать включение вопросов.
  • Автоматически создавать вопросы по заданной теме с учетом контекста.
  • Массовое назначение тестов сотрудникам с отбором по организации, подразделению, должности, с указанием срока прохождения.
  • Прохождение тестов сотрудниками, поддержка изображений в вопросах, автоматическая проверка ручных ответов через GigaChat.
  • Просмотр результатов тестирования в разрезе сотрудников, тестов, блоков, организаций, подразделений; визуализация в виде диаграмм; формирование отчетов.
  • Подача сотрудниками апелляций на результаты тестирования.
  • После успешного прохождения всех блоков текущего теста сотрудник автоматически переключается на следующий по приоритету.

Основные подсистемы


  • НСИ — ведение нормативно-справочной информации
  • Управление тестами — создание и настройка тестов
  • Тестирование — прохождение тестов сотрудниками
  • Результаты и аналитика — анализ результатов тестирования
  • Администрирование — управление системой
