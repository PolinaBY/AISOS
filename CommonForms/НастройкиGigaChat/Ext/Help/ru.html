Предназначена для настройки параметров подключения к сервису GigaChat, используемому для генерации вопросов и проверки ответов на вопросы с ручным вводом.

Открыть форму можно из раздела Нормативно-справочная информация с помощью команды Настройки Giga Chat.
 
Настройки GigaChat может изменять пользователь с ролью Администратор или Руководитель.

Параметры подключения


  • Authorization Key Ключ авторизации для доступа к API GigaChat. Выдается при регистрации в сервисе, перейти можно при нажатии на кнопку Перейти
  • Scope Область действия (область доступа), определяющая набор прав и ресурсов, к которым приложение может обращаться. Выбирается из справочника Scope
  • URL API Адрес API-сервера GigaChat (например, `https://gigachat.api.example.com`) 
  • URL авторизации Адрес для получения токена авторизации (например, `ngw.devices.sberbank.ru`)  

Важно! URL API и URL авторизации заполняются автоматически при первом запуске, изменять не рекомендуется

Включение/отключение интеграции


Не использовать GigaChat Флажок для полного отключения интеграции с GigaChat. При установке флажка генерация вопросов и проверка ответов будут недоступны 

Порядок настройки


  1. Установите флажок Не использовать GigaChat в положение Выключено (снимите флажок) для включения интеграции.
  2. Заполните поле Authorization Key — скопируйте ключ из личного кабинета GigaChat, получить можно после нажатия на кнопку Перейти.
  3. Выберите Scope — область действия в соответствии с вашим тарифным планом.
  4. Нажмите Записать и закрыть.

Проверка подключения


После сохранения настроек рекомендуется проверить работоспособность подключения, выполнив генерацию тестового вопроса в справочнике Вопросы.

Признаки корректной настройки:

  • Генерация вопроса выполняется без ошибок
  • Для вопросов с ручным вводом при тестировании отображается результат проверки

Признаки некорректной настройки:

  • Ошибка подключения к API
  • Отсутствие результата проверки ручных ответов
  • Сообщения об ошибках авторизации

Рекомендации по безопасности


  1. Authorization Key хранится в форме, не передавайте его третьим лицам.
  2. Рекомендуется периодически обновлять ключ авторизации.
  3. При отключении интеграции (флажок Не использовать GigaChat установлен) сервис не используется, что исключает обращение к внешнему API.

Возможные ошибки и их устранение


  • Не удалось получить токен. Неверный Authorization Key или URL авторизации. Проверьте правильность ввода ключа и адреса 
  • Ошибка HTTP: 401. Недействительный ключ авторизации. Обновите ключ в личном кабинете GigaChat
  • Ошибка HTTP: 404. Неверный URL API. Проверьте адрес API-сервера 
  • Таймаут соединения. Проблемы с сетью или недоступность сервера. Проверьте интернет-соединение, повторите попытку позже
  • GigaChat отключен в настройках. Установлен флажок «Не использовать GigaChat». Снимите флажок для включения интеграции
