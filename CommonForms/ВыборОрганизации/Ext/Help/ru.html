Форма позволяет пользователю выбрать организацию, которая будет использоваться как текущая при работе в программе. Выбранная организация сохраняется в параметрах сеанса и в хранилище системных настроек для последующих сеансов работы.

Порядок работы:

  • При открытии формы загружается сохраненная ранее организация
  • Пользователь может изменить организацию в поле ввода
  • При изменении организации обновляются параметры сеанса и сохраняются настройки для текущего пользователя
