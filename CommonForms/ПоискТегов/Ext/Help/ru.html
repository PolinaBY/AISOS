Предназначена для удобного назначения тегов блоку вопросов. Позволяет быстро добавлять теги из списка доступных, удалять выбранные, редактировать существующие и создавать новые.

Открыть форму можно из элемента справочника «Блоки вопросов» при нажатии на поле/кнопку «Теги не заданы».

Доступные действия

  • Выбор тегов — в левой области отображаются доступные теги. При нажатии на тег он перемещается в область выбранных тегов.
  • Удаление тегов — в области выбранных тегов нажмите кнопку с крестиком (✕) для удаления тега. Тег переместится обратно в область доступных.
  • Редактирование тегов — в области выбранных тегов нажмите кнопку с иконкой карандаша (✎) для редактирования тега. Откроется форма редактирования тега.
  • Поиск тегов — в верхней части формы расположено поле «Тег». Введите текст и нажмите `Enter` или значек Лупы— список доступных тегов отфильтруется.
  • Создание нового тега — нажмите кнопку «Создать тег». Откроется форма создания нового тега. Введённый в строке поиска текст автоматически подставится в поле наименования нового тега.
  • Сброс выбора — нажмите кнопку «Заполнить» для очистки всех выбранных тегов и строки поиска.
  • Сохранение выбора — нажмите кнопку «Задать теги» для сохранения выбранных тегов и закрытия формы. Выбранные теги будут привязаны к текущему блоку вопросов.
